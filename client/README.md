# Asset Management System

A web-based Asset Management System designed to manage, track, assign, and monitor company assets throughout their complete lifecycle.

## Features

### Authentication

* Splash screen and secure login
* User selection from registered users
* Password authentication
* User session and logout

### Dashboard

* Asset, employee, user, active asset, and task statistics
* Asset tree for quick navigation
* Asset search and filtering
* Category-wise asset statistics

### Asset Management

* View all assets
* Search and filter assets
* Add, edit, and delete assets
* View detailed asset information
* Track asset status, location, department, company, and other information

### Asset Assignment

* Search employees and available assets
* Assign assets to employees
* Track current asset ownership

### Asset Release & History

* Release assets from employees
* Automatically make released assets available
* Maintain previous employee history
* Track received date, release date, and release reason

### Employee Management

* Create and manage employees
* Search and filter employees
* View employee details
* View assets currently assigned to each employee

### Asset Import

* Import multiple assets using Excel
* Validate required asset information
* Create bulk asset records

### Asset Export

* Filter asset records
* Select required information
* Export asset data to Excel

### Settings

The Settings module contains:

* **User Management** — Create, edit, view, and delete users
* **Vendor Management** — Manage asset vendors
* **Company Information** — Manage company, location, department, equipment, brand, status, and task information

## Asset Lifecycle

**Create → Available → Assign → Track → Release → Available → Reassign / Maintenance / Retire**

The system maintains the complete history of asset usage and employee assignments.

## Main Workflow

**Login → Dashboard → Manage Assets → Assign Assets → Manage Employees → Import/Export → Settings**

## Purpose

The system provides centralized asset information, faster asset management, employee accountability, standardized data, reporting capabilities, and complete asset lifecycle tracking.
